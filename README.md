# REZO

Installers for REZO, an anime zombie survival game you can play alone or online with friends. Windows only.

**[Download the latest version](https://github.com/heyu70/rezo-downloads/releases/latest)**: open the link, then click `REZO-Setup-...exe` under Assets.

## Installing

1. Run the file you downloaded.
2. Windows may say "Windows protected your PC", because the game isn't code-signed. Click **More info**, then **Run anyway**.
3. Your antivirus may react for the same reason. Only let it through if you trust whoever sent you here.

## Updates

Open the game's launcher and click **Check for updates**. If that ever fails, come back here and install the new version over the old one. Your save stays where it is.

## Playing together

Everyone needs the same version. In the main menu choose **Party**, create a party and send your friends its code. They enter the code and join. Whoever creates the party hosts it, so the match ends if they leave.

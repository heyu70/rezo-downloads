# REZO

Installers for REZO, an anime zombie survival game you can play alone or online with friends. For Windows and Android.

**[Download the latest version](https://github.com/heyu70/rezo-downloads/releases/latest)**: open the link, then under Assets click `REZO-Setup-...exe` for Windows or `REZO-Android-...apk` for Android.

## Installing on Windows

1. Run the file you downloaded.
2. Windows may say "Windows protected your PC", because the game isn't code-signed. Click **More info**, then **Run anyway**.
3. Choose where to put the game. It always gets a folder of its own, so choosing `D:\Games` puts it in `D:\Games\REZO`.
4. Your antivirus may react because the game isn't code-signed. Only let it through if you trust whoever sent you here.

To move the game later, run the installer again and choose another folder.

## Installing on Android

Needs Android 8 or newer. It's a big game: a recent phone will run it best, and older ones may struggle.

1. Open the `.apk` you downloaded.
2. Android will ask you to allow installs from your browser or file manager, because the game isn't from the Play Store. Only allow it if you trust whoever sent you here.
3. The first launch takes longer than the rest.

To update, install the newer `.apk` over the old one. Your save stays. Uninstalling deletes the save, so use **Settings → Data → Export save** first if you ever need to.

## Updates on Windows

Open the game's launcher and click **Check for updates**. If that ever fails, come back here and install the new version over the old one. Your save stays where it is.

## Playing together

Everyone needs the same version. In the main menu choose **Party**, create a party and send your friends its code. They enter the code and join. Whoever creates the party hosts it, so the match ends if they leave. Phones and PCs can play together.
